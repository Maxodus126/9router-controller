Sekali klik

Start & Stop

Jujur

Status hidup

Health check tiap 5 detik: RUNNING, DEGRADED, EXTERNAL, atau STOPPED.

🖥️
Real-time

Live Console

Semua stdout server mengalir ke jendela app dengan timestamp — plus tombol Clear.

🪟
Selalu siap

Tray + Auto-start

Menghilang ke system tray, dan bisa menyala sendiri saat Windows boot (tanpa admin).

Fitur lengkap

Dirawat sampai ke detail kecil.

Kontrol

Copy API URL

Port terdeteksi otomatis dari banner 9router — bukan angka mati. Salin dengan satu klik.
