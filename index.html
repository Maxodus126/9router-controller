Fitur

Satu tombol, semua yang kamu butuh.

Dibuat untuk satu pekerjaan: menghidupkan & mematikan 9router dengan nyaman — tanpa menghafal perintah.

⚡ Start / Stop sekali klik

Menjalankan npx 9router --tray di background — tanpa jendela terminal, tanpa menu yang nunggu input.

🟢 Status hidup yang jujur

Health check tiap 5 detik. Hijau = sehat, Amber = proses ada tapi tak merespons, Merah = mati.

📊 Uptime & RAM

Pantau berapa lama jalan dan konsumsi RAM seluruh proses 9router — diperbarui otomatis.

🖥️ Live Console

stdout real-time dengan timestamp, ditampilkan di jendela app. Tombol Clear untuk membersihkan.

📋 Copy API URL

Salin http://localhost:20128/v1 sekali klik. Port otomatis terdeteksi dari output 9router.

🔄 Restart cepat

Stop lalu start lagi dengan satu tombol — pas untuk coba ulang setelah ubah konfigurasi.

🩺 Port Doctor

Pindai & bunuh proses yang mengunci port — dengan konfirmasi dulu sebelum membunuh apa pun.

🛡️ Auto-restart on crash

Kalau server tiba-tiba mati, app menghidupkannya lagi otomatis (maks 3× berturut-turut).

🪟 System tray

Tutup jendela → app lanjut di tray. Ikon berubah warna mengikuti status. Menu klik kanan lengkap.

🚀 Auto-start Windows

Bisa langsung menyala saat boot (registry HKCU, per-user, tanpa admin).
